นโยบายความเป็นส่วนตัว

มีผลตั้งแต่ 6 พฤศจิกายน 2026 · ODIN Studio

บริการ Google ที่แอปจัดเตรียมข้อมูลรับรองไว้ใช้กับเวอร์ชัน 1.2 ขึ้นไป รุ่นก่อนหน้าใช้คีย์ Google ที่ผู้ใช้ตั้งค่าเอง โดยโควตา ค่าใช้จ่าย และการจัดการข้อมูลของ Google เป็นไปตามบัญชีของผู้ใช้รุ่นนั้น

งานตัดต่อในเครื่อง

ไฟล์ต้นฉบับ ไทม์ไลน์ โปรเจกต์ .odin ประวัติแชทที่บันทึกในโปรเจกต์ และไฟล์ส่งออกอยู่ในเครื่องหรือตำแหน่งที่คุณเลือก ผู้พัฒนาไม่ได้มีเซิร์ฟเวอร์รับไฟล์ต้นฉบับของคุณ การนำเข้าสื่อหรือเล่นพรีวิวด้วยตัวเองไม่อัปโหลดวิดีโอไปให้ผู้พัฒนา

ข้อมูลที่ส่งให้ OpenAI เมื่อเลือกใช้ AI

หลังอนุญาตและส่งข้อความ แชท Codex ส่งข้อความ ข้อมูลโปรเจกต์ที่จำเป็น เช่นชื่อสื่อ ระยะเวลาและคำสั่งตัดต่อ รวมถึงภาพจากคลิปที่เครื่องมือเลือกให้ OpenAI ประมวลผลผ่านบัญชี ChatGPT ของคุณ ไม่ส่งข้อมูล bookmark ที่ให้สิทธิ์เข้าถึงไฟล์ของ macOS การลงชื่อเข้าใช้ OpenAI ประมวลผลข้อมูลบัญชี เช่นอีเมลและตัวระบุบัญชี ตามเงื่อนไขของผู้ให้บริการ การเก็บประวัติและการใช้ข้อมูลขึ้นอยู่กับบัญชีและการตั้งค่าของคุณ อ่าน นโยบาย OpenAI และ วิธีลงชื่อเข้าใช้ Codex

เสียงออนไลน์ Google Gemini

เมื่ออนุญาตและเลือกสร้างเสียง Gemini แอปส่งบทพากย์ ชื่อเสียง และแนวการอ่านไปยัง Google โดยตรงเพื่อสร้างเสียง โดยใช้ข้อมูลรับรองบริการ Google ที่ผู้พัฒนาจัดเตรียมไว้ในแอป ผู้ใช้ไม่ต้องกรอกคีย์ API ของ Google เอง ความพร้อมใช้งานขึ้นกับสถานะบริการและโควตาของผู้ให้บริการ Google อาจเก็บหรือใช้ข้อมูลตามเงื่อนไขบริการและประเภทบัญชีที่ใช้ให้บริการ อ่าน ข้อกำหนด Gemini API และ นโยบาย Google เสียง macOS สร้างในเครื่องโดยไม่ส่งบทพากย์ให้ Google

ข้อมูลในเครื่องและข้อมูลรับรอง

แอปเก็บการตั้งค่าในพื้นที่แอป ใช้ security-scoped bookmarks เพื่อเปิดไฟล์ที่คุณเลือกอีกครั้ง และใช้ macOS Keychain สำหรับคีย์ Gemini และข้อมูลลงชื่อเข้าใช้ Codex ของรุ่น App Store บทและไฟล์เสียงที่สร้างแยกจากวิดีโอจะบันทึกในพื้นที่แอปบน Mac เพื่อเปิดฟังและส่งออกได้ ไฟล์สื่อที่สร้างและประวัติการทำงานอาจอยู่ในพื้นที่แอป โปรเจกต์ หรือพื้นที่แคชจนคุณลบ เราไม่บันทึกคีย์ API หรือโทเค็นลงในโปรเจกต์

การถอดเสียงและแยกผู้พูด

คุณเลือกถอดเสียงในเครื่องด้วย Speech ของ macOS เมื่อรองรับภาษาและขอสิทธิ์แล้วได้ โดยโหมดนี้ไม่แยกผู้พูดอัตโนมัติ ไม่มีการเปลี่ยนไปใช้คลาวด์แทนโดยอัตโนมัติ

เมื่อเลือก Gemini สำหรับถอดเสียงและแยกผู้พูด แอปขออนุญาตแยกต่างหากก่อนส่งเสียงที่เตรียมจากไทม์ไลน์ ภาษา และคำสั่งวิเคราะห์ไป Google โดยใช้ข้อมูลรับรองบริการ Google ที่แอปจัดเตรียมไว้ การส่งเสียงใช้โควตาของบริการและขึ้นกับความพร้อมของผู้ให้บริการ แอปขอให้ Gemini ไม่บันทึก Interaction ผ่าน store:false แต่ไม่ได้รับประกันว่า Google ไม่เก็บข้อมูลสำหรับการรักษาความปลอดภัยหรือวัตถุประสงค์อื่นตามเงื่อนไขบริการ ไฟล์เสียงชั่วคราวที่ใช้ส่งจะถูกลบเมื่อการวิเคราะห์จบหรือถูกยกเลิก ผลถอดเสียง ป้ายผู้พูด เวลา ข้อความเดิมและข้อความที่ปรับให้อ่านง่ายอาจบันทึกในโปรเจกต์ .odin ป้ายผู้พูดเป็นการประมาณเสียง ไม่ใช่การยืนยันตัวตนจริง กรุณาตรวจผลก่อนใส่ซับหรือส่งออก

การโฆษณาและการติดตาม

ODIN Studio ไม่มีโฆษณา ไม่มีการติดตามเพื่อโฆษณา และปิด analytics ของ Codex ที่ฝังในรุ่น App Store บริการภายนอกยังได้รับข้อมูลเครือข่ายที่จำเป็นต่อการให้บริการตามนโยบายของบริการนั้น

การควบคุมและการลบข้อมูล

คุณเลือกตัดต่อเองโดยไม่ใช้ AI ได้ ตั้งค่าให้ถามการอนุญาต AI ใหม่ใน Studio Settings และลงชื่อออกจาก Codex ในเมนูบัญชีได้ ลบประวัติที่บันทึกในไฟล์โดยลบโปรเจกต์หรือสร้างโปรเจกต์ใหม่ สำรองงานก่อนลบไฟล์ ข้อมูลที่ OpenAI เก็บต้องจัดการผ่านบัญชี OpenAI ของคุณ สำหรับข้อมูลที่ส่งผ่านบริการ Google ที่แอปจัดเตรียมไว้ สามารถติดต่อผู้พัฒนาเพื่อขอความช่วยเหลือได้ การเก็บและลบข้อมูลเป็นไปตามนโยบายของผู้ให้บริการ

การติดต่อซัพพอร์ต

หากส่งอีเมล ผู้พัฒนาได้รับอีเมลและข้อมูลที่คุณเลือกส่งเพื่อแก้ปัญหา เราใช้เพื่อซัพพอร์ตและไม่ขายข้อมูล กรุณาไม่ส่งรหัสผ่าน คีย์ API หรือสื่อส่วนตัวที่ไม่จำเป็น ติดต่อ thisadee3887@icloud.com เพื่อสอบถามหรือขอลบอีเมลซัพพอร์ต เว็บไซต์นี้โฮสต์บน GitHub Pages ซึ่งประมวลผลข้อมูลการเข้าถึงตาม นโยบาย GitHub

Privacy summary in English

Manual editing keeps original media and projects on your Mac. Optional Codex chat sends prompts, relevant project metadata and sampled video frames directly to OpenAI using your ChatGPT account after consent. In version 1.2 and later, optional Gemini TTS sends narration text and voice settings directly to Google after consent using the Google service credential provisioned by the developer in the app. Earlier versions use the Google API key configured by the user and that user account's quota, provider charges and data controls. Users do not need to configure their own Google API key. Optional Gemini audio transcription and speaker labeling sends prepared timeline audio, language and analysis instructions directly to Google with separate consent using the same app-provisioned credential. Availability depends on provider service status and quotas. Standalone narration scripts and completed audio takes are stored locally in the app data area for audition and WAV export, independently of video projects. The request sets store:false; other provider retention follows its terms. Temporary extracted audio is removed when analysis ends or is cancelled. Transcripts, original and readable text, estimated speaker labels and timings may be saved in your local project. Provider retention and processing follow the applicable provider account and terms. OpenAI data controls are managed through your own OpenAI account; contact the developer for assistance with requests concerning the app-provisioned Google service. ODIN does not operate a media-upload backend or advertising tracker. Credentials use macOS Keychain in the App Store build. Contact the support email above for questions.
