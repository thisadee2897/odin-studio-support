ต้องการความช่วยเหลือ?

ติดต่อ thisadee3887@icloud.com พร้อมรุ่น macOS รุ่นแอป และขั้นตอนที่ทำให้เกิดปัญหา ไม่ต้องส่งรหัสผ่าน คีย์ API หรือวิดีโอส่วนตัว

เริ่มต้นใช้งาน

  1. กดเพิ่มสื่อ เลือกวิดีโอ ภาพ หรือเสียงในเครื่อง
  2. เพิ่มคลิปลงไทม์ไลน์ ลากเพื่อย้ายหรือยืดหดจากขอบคลิป ใช้ปุ่มเล่น/หยุดในแถบไทม์ไลน์
  3. เลือกชิ้นงานหรือคลิกขวาเพื่อแก้เวลา ความดัง หรือรูปแบบซับ ใช้ Undo เมื่อต้องการย้อนกลับ
  4. ใช้เมนูโปรเจกต์บันทึกไฟล์ .odin และเก็บไฟล์ต้นฉบับไว้ในตำแหน่งเดิม
  5. กดส่งออกเพื่อสร้างวิดีโอสำเร็จ เลือก H.264 หรือ HEVC ใน Settings

AI และเสียงออนไลน์

การตัดต่อด้วยตัวเองไม่ต้องลงชื่อเข้าใช้ ChatGPT แชท Codex เป็นบริการเสริมที่ใช้บัญชี ChatGPT ของคุณ โมเดลและโควตาขึ้นอยู่กับบัญชี ในเวอร์ชัน 1.2 บริการเสียง Gemini ที่แอปจัดเตรียมไว้ใช้งานได้โดยไม่ต้องกรอกคีย์ API ของ Google เอง โดยต้องอนุญาตส่งบทไปประมวลผลก่อน และขึ้นกับความพร้อมและโควตาของบริการ แอปมีเสียง macOS สำหรับการสร้างเสียงในไทม์ไลน์ในเครื่องด้วย

สร้างไฟล์เสียง AI แยกจากวิดีโอ — เวอร์ชัน 1.2

เปิดแท็บเสียง เลือกเสียงและฟังตัวอย่าง วางบทพูดทั้งบท แล้วกดสร้างไฟล์เสียงทั้งบทได้โดยไม่ต้องมีคลิปวิดีโอ เมื่อสร้างสำเร็จให้ฟังตรวจชื่อเฉพาะและประโยคท้ายก่อนส่งออก WAV เลือกคุณภาพต้นฉบับ หรือแปลงเป็น PCM 48 kHz / 24-bit สำหรับโปรแกรมตัดต่อ รายละเอียดเสียงยังคงมาจากไฟล์ต้นฉบับ การสร้างเสียงออนไลน์อาจใช้เวลาหลายนาที และผลการออกเสียงหรือจังหวะอาจต้องปรับบทแล้วสร้างใหม่

ซับและสำเร็จรูป

แท็บสำเร็จรูปมีซับ ข้อความเคลื่อนไหว Subscribe, Intro, Outro และ Transition พร้อมเสียงที่เปลี่ยนหรือปิดได้ เลือกชิ้นบนไทม์ไลน์เพื่อปรับรายละเอียด ซับผู้พูดแยกแถว CC ตามป้ายเสียง และเปลี่ยนสีหรือแก้ผู้พูดเองได้

ถอดเสียงและแยกผู้พูด

ที่แท็บเสียง เลือก macOS เพื่อถอดในเครื่องเมื่อรองรับภาษา หรือเลือก Gemini เพื่อถอดเสียงและประมาณผู้พูดผ่านบริการที่แอปจัดเตรียมไว้ โหมด Gemini ขออนุญาตส่งเสียงแยกต่างหาก และขึ้นกับความพร้อมและโควตาของบริการ ตรวจคำ เวลา ป้ายผู้พูด และเทียบข้อความเดิมกับข้อความอ่านง่ายก่อนใส่ซับ ผล AI อาจผิดหรือมีคำตกหล่นได้

ไฟล์ต้นฉบับหาไม่เจอ

หากย้ายไฟล์หรือสิทธิ์หมดอายุ ให้เลือกไฟล์ต้นฉบับอีกครั้งเมื่อแอปถาม โปรเจกต์ .odin เก็บคำสั่งตัดต่อและอ้างอิงสื่อ จึงควรเก็บสื่อต้นฉบับด้วย
