งานตัดต่อในเครื่อง

ไฟล์ต้นฉบับ ไทม์ไลน์ โปรเจกต์ .odin ประวัติแชทที่บันทึกในโปรเจกต์ และไฟล์ส่งออกอยู่ในเครื่องหรือตำแหน่งที่คุณเลือก ผู้พัฒนาไม่ได้มีเซิร์ฟเวอร์รับไฟล์ต้นฉบับของคุณ การนำเข้าสื่อหรือเล่นพรีวิวด้วยตัวเองไม่อัปโหลดวิดีโอไปให้ผู้พัฒนา

ข้อมูลที่ส่งให้ OpenAI เมื่อเลือกใช้ AI

หลังอนุญาตและส่งข้อความ แชท Codex ส่งข้อความ ข้อมูลโปรเจกต์ที่จำเป็น เช่นชื่อสื่อ ระยะเวลาและคำสั่งตัดต่อ รวมถึงภาพจากคลิปที่เครื่องมือเลือกให้ OpenAI ประมวลผลผ่านบัญชี ChatGPT ของคุณ ไม่ส่งข้อมูล bookmark ที่ให้สิทธิ์เข้าถึงไฟล์ของ macOS การลงชื่อเข้าใช้ OpenAI ประมวลผลข้อมูลบัญชี เช่นอีเมลและตัวระบุบัญชี ตามเงื่อนไขของผู้ให้บริการ การเก็บประวัติและการใช้ข้อมูลขึ้นอยู่กับบัญชีและการตั้งค่าของคุณ อ่าน นโยบาย OpenAI และ วิธีลงชื่อเข้าใช้ Codex

เสียงออนไลน์ Google Gemini

เมื่ออนุญาตและเลือกสร้างเสียง Gemini แอปส่งบทพากย์ ชื่อเสียง รูปแบบเสียง และคีย์ API ไปยัง Google โดยตรงเพื่อสร้างเสียง Google อาจเก็บหรือใช้ข้อมูลตามเงื่อนไขบริการและประเภทบัญชีของคุณ อ่าน ข้อกำหนด Gemini API และ นโยบาย Google เสียง macOS สร้างในเครื่องโดยไม่ส่งบทพากย์ให้ Google

ข้อมูลในเครื่องและข้อมูลรับรอง

แอปเก็บการตั้งค่าในพื้นที่แอป ใช้ security-scoped bookmarks เพื่อเปิดไฟล์ที่คุณเลือกอีกครั้ง และใช้ macOS Keychain สำหรับคีย์ Gemini และข้อมูลลงชื่อเข้าใช้ Codex ของรุ่น App Store ไฟล์สื่อที่สร้างและประวัติการทำงานอาจอยู่ในโปรเจกต์หรือพื้นที่แคชจนคุณลบ เราไม่บันทึกคีย์ API หรือโทเค็นลงในโปรเจกต์

การถอดเสียงและแยกผู้พูด

คุณเลือกถอดเสียงในเครื่องด้วย Speech ของ macOS เมื่อรองรับภาษาและขอสิทธิ์แล้วได้ โดยโหมดนี้ไม่แยกผู้พูดอัตโนมัติ ไม่มีการเปลี่ยนไปใช้คลาวด์แทนโดยอัตโนมัติ

เมื่อเลือก Gemini สำหรับถอดเสียงและแยกผู้พูด แอปขออนุญาตแยกต่างหากก่อนส่งเสียงที่เตรียมจากไทม์ไลน์ ภาษา และคำสั่งวิเคราะห์ไป Google โดยใช้คีย์ API เดิมของคุณ การส่งเสียงใช้โควตาของ Google และอาจมีค่าใช้จ่าย แอปขอให้ Gemini ไม่บันทึก Interaction ผ่าน store:false แต่ไม่ได้รับประกันว่า Google ไม่เก็บข้อมูลสำหรับการรักษาความปลอดภัยหรือวัตถุประสงค์อื่นตามเงื่อนไขบริการ ไฟล์เสียงชั่วคราวที่ใช้ส่งจะถูกลบเมื่อการวิเคราะห์จบหรือถูกยกเลิก ผลถอดเสียง ป้ายผู้พูด เวลา ข้อความเดิมและข้อความที่ปรับให้อ่านง่ายอาจบันทึกในโปรเจกต์ .odin ป้ายผู้พูดเป็นการประมาณเสียง ไม่ใช่การยืนยันตัวตนจริง กรุณาตรวจผลก่อนใส่ซับหรือส่งออก

การโฆษณาและการติดตาม

ODIN Studio ไม่มีโฆษณา ไม่มีการติดตามเพื่อโฆษณา และปิด analytics ของ Codex ที่ฝังในรุ่น App Store บริการภายนอกยังได้รับข้อมูลเครือข่ายที่จำเป็นต่อการให้บริการตามนโยบายของบริการนั้น

การควบคุมและการลบข้อมูล

คุณเลือกตัดต่อเองโดยไม่ใช้ AI ได้ ตั้งค่าให้ถามการอนุญาต AI ใหม่ใน Studio Settings และลงชื่อออกจาก Codex ในเมนูบัญชีได้ ลบประวัติที่บันทึกในไฟล์โดยลบโปรเจกต์หรือสร้างโปรเจกต์ใหม่ สำรองงานก่อนลบไฟล์ การลบข้อมูลที่ผู้ให้บริการเก็บต้องจัดการผ่านบัญชี OpenAI หรือ Google ของคุณ

การติดต่อซัพพอร์ต

หากส่งอีเมล ผู้พัฒนาได้รับอีเมลและข้อมูลที่คุณเลือกส่งเพื่อแก้ปัญหา เราใช้เพื่อซัพพอร์ตและไม่ขายข้อมูล กรุณาไม่ส่งรหัสผ่าน คีย์ API หรือสื่อส่วนตัวที่ไม่จำเป็น ติดต่อ thisadee3887@icloud.com เพื่อสอบถามหรือขอลบอีเมลซัพพอร์ต เว็บไซต์นี้โฮสต์บน GitHub Pages ซึ่งประมวลผลข้อมูลการเข้าถึงตาม นโยบาย GitHub

Privacy summary in English

Manual editing keeps original media and projects on your Mac. Optional Codex chat sends prompts, relevant project metadata and sampled video frames directly to OpenAI using your ChatGPT account after consent. Optional Gemini TTS sends narration text, voice settings and your API key directly to Google after consent. Optional Gemini audio transcription and speaker labeling sends prepared timeline audio, language and analysis instructions directly to Google with separate consent and your existing API key. It uses your Google quota and may incur provider charges. The request sets store:false; other provider retention follows its terms. Temporary extracted audio is removed when analysis ends or is cancelled. Transcripts, original and readable text, estimated speaker labels and timings may be saved in your local project. Provider retention and processing follow your provider account and terms. ODIN does not operate a media-upload backend or advertising tracker. Credentials use macOS Keychain in the App Store build.
